xdata-kr provides an AI-driven automation data and API platform offering over 200 automated services across tax, finance, marketing, and workflow automation. Users can integrate AI models like Claude and ChatGPT via REST APIs to streamline tasks such as tax filing, payroll, corporate banking, and advertising analytics. The platform includes a marketplace of data products, customizable AI pipelines, and a developer portal for building and deploying automated workflows.

**Areas:** AI · Automation · Data · API Platform · Finance
